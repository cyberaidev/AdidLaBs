# AdidLaBs HDR Frontend Redesign

This revision changes the visual presentation only. Existing API calls, Cognito authentication, Bedrock AgentCore orchestration, MCP/LiteLLM integration, weather retrieval, bag, wishlist, account, stylist chat, terminal, telemetry and agent status logic remain unchanged.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

## Production build

```bash
cd frontend
npm install
npm run build
```

The HDR hero currently uses a generic, unbranded athlete photograph loaded from Unsplash. No third-party trademark logo is included.
